# Question 1: EnterpriseDB SQL Practical

## Objective
Create a database named EnterpriseDB and perform SQL queries on Departments and Employees.

## Database Setup
- Database: EnterpriseDB
- Departments table: 5 records
- Employees table: 15 records
- Department 50 (Research and Development) has no employees.

## Queries Performed
1. Verify department and employee record counts.
2. Find employees earning above their department's average salary.
3. Find the second-highest distinct salary.
4. Rank the top three employees per department using RANK().

## Expected Results
- Total departments: 5
- Total employees: 15
- Second-highest distinct salary: 100000.00
